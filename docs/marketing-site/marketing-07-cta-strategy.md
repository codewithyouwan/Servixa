# Call-to-Action Strategy

## 1. The two CTAs, and the rule for using them

There are exactly two primary conversion CTAs on this entire site:
- **"Post Your Project Free →"** (homeowner)
- **"Join as a Contractor →"** (contractor)

Every other button on the site (Learn More, See Pricing, Read Reviews) is a secondary, informational CTA that exists to move a visitor toward one of these two, not to compete with them. Diluting the site with multiple "primary-feeling" CTAs (Sign Up, Get Started, Learn AI, Try Now) is the most common way marketplace marketing sites confuse visitors about what action actually matters — every page in this spec should be checked against this rule.

## 2. Placement pattern (applies to every page)

- **Nav bar** — persistent, sticky, audience-appropriate label (see navigation doc). Always present, always one click away, regardless of scroll position.
- **Hero** — both primary CTAs present together only on audience-neutral pages (Home). On audience-specific pages (`/homeowners`, `/contractors`), only that audience's CTA appears in the hero — showing "Join as a Contractor" prominently on the homeowner page is a distraction, not a courtesy.
- **Mid-page, after value is established** — at least one CTA placement after the "how it works" section, since that's the point in the page where a visitor has enough context to act without yet needing full trust-building — this is the "strike while intent is warm" placement.
- **After trust content** — a CTA following the trust/verification section, for the visitor who was withholding action specifically until credibility was established.
- **Final CTA band** — every single page ends with a clear, high-contrast CTA section — no page should end on a content section (like an FAQ or footer) without one more conversion opportunity first.
- **Sticky mobile bar** — on mobile, a persistent bottom CTA bar (audience-appropriate) so the action is always reachable without scrolling back up, which matters disproportionately on mobile where scroll-back friction is higher.

## 3. Secondary CTA hierarchy

Below the two primary CTAs, in descending order of intent:
1. **"See Pricing"** / **"See AI Features"** — consideration-stage, used when a visitor needs one more piece of information before they'll commit to the primary action.
2. **"Read Reviews"** / **"Learn About Trust & Safety"** — trust-stage, used specifically near objection-handling content.
3. **"Log In"** — utility-stage, for returning users; always the lowest visual weight of any CTA on the page (text link, not a button) so it never competes with new-visitor conversion.

## 4. Audience-specific CTA copy variants

Using the identical button copy everywhere flattens the message; small variants reinforce what the visitor specifically gets:

| Context | Copy |
|---|---|
| Homepage hero / general | "Post Your Project Free →" |
| Homeowner page, after how-it-works | "Get Matched With Contractors →" |
| Homeowner page, after trust section | "Post Your Project — It's Free →" |
| Contractor page hero | "Join as a Contractor →" |
| Contractor page, after Trust Score section | "Get Verified & Start Getting Leads →" |
| Pricing page | "Post a Project Free →" / "See Contractor Pricing →" |
| Blog/cost-guide articles | "Get Free Quotes for This Project →" (contextual to the article's project type — a reader of a "kitchen remodel cost" article converts better on a kitchen-specific CTA than a generic one) |
| About page | "Get in Touch →" / "See Open Roles →" (softer, since this page's traffic includes investors/press/partners, not just homeowners/contractors) |

## 5. What to avoid

- **No more than one CTA style competing for primary attention per screen.** If a section has a primary CTA, any other button in that same viewport should be visually subordinate (outline/ghost style, smaller).
- **No CTA before its supporting content.** Every CTA placement above follows content that gives the visitor a reason to click — a "Sign Up Now" button floating with no context above it converts worse than the same button placed after value has been shown.
- **No urgency-manufacturing tactics** (fake countdown timers, "Only 3 spots left") on a trust-building marketplace site — this category of dark pattern actively undermines the credibility this entire site is built to establish, and it's inconsistent with a platform whose stated differentiator is honest, data-driven trust.
