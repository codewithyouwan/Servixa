# Visual Screen Design — FAQ

Follows `visual-00-language.md`. Header and footer identical to `visual-01-home.md`. Section spacing throughout runs tighter (32px, not 64px) than any other page — this is a dense, scan-first screen, and the visual rhythm should reflect that.

**Hero + Search.** A 40px headline, "Frequently Asked Questions," and 24px beneath it a search input — 48px tall, 1px `neutral-300` border, 8px radius, a small `neutral-500` magnifying-glass icon inset on the left — capped at about 600px wide and centered, narrower than the full container so it doesn't read oddly stretched.

**Audience tabs.** Three tabs — Homeowners, Contractors, General — same underline construction as the How It Works page's two-tab control.

**FAQ accordion.** A continuous list of rows, each 56px minimum height, a 16px semibold question on the left, a `neutral-500` chevron on the right, a 1px `neutral-300` line beneath every row whether open or closed — no gaps, no card wrapper, reading as one unbroken, quickly scannable list. An open row's answer sits in 16px `neutral-700`, 16px of top padding before the text begins.

**"Still have questions" strip.** A single centered line — icon, one sentence about response time — with an outline "Contact Us" button beneath it, same compressed treatment as the Contact page's equivalent moment.

**Testimonial / Statistics.** Both compressed to single-line treatments identical to the Contact page's — no cards, no star rows, small inline figures.

**Final CTA band.** Standard `#0A0A0A` full-bleed, dual-button treatment — this section alone reverts to the page's usual 128px spacing, since it remains the one true conversion moment even on an otherwise dense, utility-first page.
