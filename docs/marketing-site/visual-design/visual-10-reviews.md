# Visual Screen Design — Reviews

Follows `visual-00-language.md`. Header and footer identical to `visual-01-home.md`. This page's testimonial grid IS the main body — treated as the page's primary content rather than one section among several.

**Hero.** A 40px headline, "Real Reviews From Real Projects.," an 18px subtext beneath explaining the verified-project mechanism, no image.

**Statistics (summary band).** Sitting close beneath the hero — only 24px of gap, tighter than the usual 64px — three quiet figures (4.8★ average, X,000+ verified reviews, X% five-star), giving the visitor context before they scroll into the grid.

**Filter bar.** Five compact dropdowns in a single row, each a shorter 40px version of the standard select input — 1px `neutral-300` border, 8px radius, small chevron — labeled All, Category, City/State, Voice, Rating.

**Testimonial grid.** Three columns, 48px gaps, each card built exactly like Home's testimonial card (photo, name/city, five-star row in `accent-600`, quote, green "Verified Project" tag) but now the project type appears as a small 14px `neutral-500` line beneath the attribution — "Kitchen Remodel," "Roof Repair" — since browsing by project type is this page's actual use case. A "Load More" outline button sits centered beneath the grid, 64px below the last row.

**Why Reviews Here Are Different.** A single centered block after the grid — 32px headline, one paragraph, one outline link to Trust & Safety — placed after the proof rather than before it, so the visitor has already seen real, attributed reviews before being told why they can trust them.

**Final CTA band.** Standard `#0A0A0A` full-bleed, dual-button treatment.
