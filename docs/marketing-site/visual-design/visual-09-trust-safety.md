# Visual Screen Design — Trust & Safety

Follows `visual-00-language.md`. Header and footer identical to `visual-01-home.md`. This page is the calmest on the site — no `accent-600` appears at all until the final band, and every icon runs `green-600` instead of the usual quiet `neutral-500`, so the whole page reads as one continuous, unhurried trust narrative.

**Hero.** A 40px headline, "Real Verification. Real Accountability.," an 18px subtext, no buttons, no color accent — headline stays plain `ink-900`.

**Verification Process.** Three cards, standard construction, each icon (license, insurance, background-check glyphs) rendered in `green-600` rather than the default gray.

**Trust Score — the inputs, explained.** The same segmented green-to-neutral bar used on the Contractors and AI Features pages, here with four labeled ticks instead of three (Completion Rate, Response Speed, Customer Retention, Dispute History), each label sitting beneath its own tick mark in 14px `neutral-700`.

**Security.** Two cards, icons here reverting to the standard `neutral-500` (security is a distinct idea from verification and shouldn't visually blend into the green system) — "Encrypted Document Storage," "No Data Resale."

**Badge System.** Three badge-and-explanation pairs stacked vertically rather than gridded, each a slightly larger pill (32px tall): "Verified" in `green-600`-on-tint, "Top Rated" and "Platform Added" both rendered in plain `ink-900` text on a `#F9FAFB` pill — green stays reserved solely for verification, so it never gets diluted into a general-purpose "good badge" color. Each pill is followed by a 16px `neutral-700` explanatory line, with 32px gaps between the three pairs.

**Statistics.** Quiet number band, but the "100%" figure (contractors license-checked) is the single instance site-wide of a stat number rendered in `green-600` rather than `ink-900` — a deliberate, one-time exception marking this page's quality-assurance framing.

**FAQ.** Standard continuous accordion list, full trust-specific question set.

**Final CTA band.** The only moment of real visual intensity on the page — standard `#0A0A0A` full-bleed, dual `accent-600`/outline buttons — arriving as a clear, singular contrast after an otherwise deliberately quiet scroll.
