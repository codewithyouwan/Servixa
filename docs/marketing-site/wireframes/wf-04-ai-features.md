## Hierarchy & conversion notes

- Each AI capability gets its own full section rather than being crammed into a 4-up grid (unlike the homepage teaser) — this page's visitor already clicked through specifically for AI detail, so it can afford to slow down and explain, matching the depth Stripe or Linear give a dedicated feature page versus a homepage teaser.
- The comparison table is the section doing the most differentiation work on this page — placed after all four features are explained, so the ✓/✗ claims land as substantiated rather than as an opening boast.
- Dual CTA throughout (not audience-locked like the Homeowners/Contractors pages) since AI Features is a neutral, consideration-stage page visited by both audiences.
