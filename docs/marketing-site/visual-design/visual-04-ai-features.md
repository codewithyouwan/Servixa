# Visual Screen Design — AI Features

Follows `visual-00-language.md`. Header (default dual-CTA state) and footer identical to `visual-01-home.md`.

**Hero.** Shorter than Home's — roughly 560px rather than 640px, achieved by pulling in the vertical padding rather than shrinking the type. Eyebrow "AI FEATURES" in `accent-600`, a 56px headline, "AI Built for Construction, Not Chatbots," an 18px subtext grounding the claim immediately: "Trained on real project scopes, real contractor pricing, and real outcomes — not generic web text." Two 48px buttons beneath (default size, not the 56px hero-scale used on Home — a deliberate half-step down, signaling this is a secondary entry point relative to the homepage).

**AI Project Assistant.** A full-width section, 64px above and below. A 32px semibold headline, an 18px subtext, then — larger and more detailed than the equivalent moment on Home — the same before/after visual: a plain-bordered rectangle on the left holding loose typed text on the `#F9FAFB` tint, an arrow glyph, and on the right a crisp white card with the soft shadow token showing a labeled scope-of-work summary with category, budget range, and timeline rows, each row a small `neutral-500` icon beside 14px text.

**Smart Matching Engine.** No cards here — six inline chips wrap across the container width, each a 24px `neutral-500` icon followed by an 16px `ink-900` label (Category, Location, Budget, Availability, Ratings, Track Record), 16px gaps between chips. The lack of card borders here is deliberate: these six things are inputs to one idea, not six separate concepts each deserving its own boxed treatment.

**Trust Score.** The identical segmented-bar visual used on the Contractors page, reused exactly rather than redrawn — same green-to-neutral gradient bar, same four labeled ticks beneath it.

**AI Proposal Drafting.** The shortest section on the page — a 32px headline, one line of 18px supporting copy, and a single outline-style button, "For Contractors," with no further visual elaboration, since the full explanation of this feature lives on the Contractors page.

**How We're Different.** A bordered table, 1px `neutral-300` frame, 12px radius, header row on the `#F9FAFB` tint. Four columns: a blank label column, then "Us," "Traditional Directories," "Generic Lead-Gen." The "Us" column carries a 3px `accent-600` top border and a very faint `#F9FAFB` column tint, visually flagging it without a heavy fill. Rows read: AI-generated scope, Verified-only matching, Live Trust Score — each cell holding either a small `green-600` check or a `neutral-300` dash, never red, since an absent competitor feature isn't an error, just a neutral gap.

**Final CTA band.** Same `#0A0A0A` full-bleed treatment and 56px dual buttons as Home's — this page's closing moment gets the same full weight as the homepage's.
